Kdens-Reforger-Ballistics-Calculator

Arma Reforger fire solution tool for M777 howitzer and US 81mm mortar. Enter 8-digit grids plus gun/target elevation to calculate azimuth, range, corrected elevation, and time of flight.

Preset firing points / objectives

Select a known point for the gun or target. After the gun position is set, the target list only shows preset points that are in range for the selected weapon/table.
Select a gun position or enter a manual gun grid to filter target presets by range.

Absolute coordinate adjustment

Moves the target grid by 10 meters in absolute map coordinates and recalculates without saving.
No absolute adjustment applied.

Line-of-fire adjustment

Moves the target grid relative to the current gun-to-target line. Add / Drop moves farther or closer. Left / Right moves perpendicular to the line of fire.
No line-of-fire adjustment applied.

Manual mil trim

Fine-tune the final solution in 1 mil increments. This changes the displayed and saved fire mission values.
No manual mil trim applied.
Height correction uses high-angle table logic: final elevation = table elevation - atan((target elev - gun elev) / range), converted to mils. If the game mod behaves differently, tune the correction factor.

Backup / Load / Save Missions

History is saved in this browser using localStorage. Use backup files to move missions between browsers/devices.
